# Joshua Catulin — Personal Portfolio

A responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

## Live Demo
https://joshcatulin.github.io/portfolio-Catulin/#home

## Features
- Animated typing intro (Typed.js)
- Light/dark mode toggle
- Responsive navigation with mobile menu
- Scroll-based reveal animations (ScrollReveal.js)
- About, Skills, and Contact sections
- Contact form powered by Formspree

## Tech Stack
- HTML5
- CSS3 (custom properties / CSS variables for theming)
- Vanilla JavaScript
- [Typed.js](https://github.com/mattboldt/typed.js/)
- [ScrollReveal](https://scrollrevealjs.org/)
- [Boxicons](https://boxicons.com/)
